# Multifidelity Kernel Regression

A Python implementation of multifidelity kernel regression that combines high-fidelity and low-fidelity data to achieve variance reduction in predictions. This method applies the Multifidelity Monte Carlo (MFMC) estimator framework to kernel regression problems.

## Motivation

In many scientific and engineering applications, **high-fidelity data is expensive and scarce**. For example:
- High-resolution simulations require significant computational resources
- Physical experiments are costly and time-consuming
- Detailed measurements require expensive equipment

Standard kernel regression often relies solely on high-fidelity data, leading to **high variance in predictions** when data is limited. This package addresses this limitation by incorporating cheaper low-fidelity data to improve prediction robustness.

## Theory

### Standard Kernel Regression

Kernel regression (also known as Nadaraya-Watson regression) is a non-parametric method that estimates the conditional expectation of a random variable. Given:

- $X \in \mathbb{R}^d$: d-dimensional input variable
- $f_1: \mathbb{R}^d \to \mathbb{R}$: high-fidelity input-output map
- $Y_1 = f_1(X)$: high-fidelity output variable
- $\lbrace (x_i, y_i) \rbrace_{i=1}^{n}$: n i.i.d. training samples

For an unseen point $x^\ast$, kernel regression predicts the output as a **weighted average of training data**:

$$E[Y_1|X=x^\ast] \approx \sum_{i=1}^{n} w_i(x^\ast) y_i$$

where the weights are computed using a kernel function $K_h$:

$$w_i(x^\ast) = \frac{K_h(x^\ast - x_i)}{\sum_{j=1}^{n} K_h(x^\ast - x_j)}$$

For a scalar bandwidth $h>0$ and an input displacement $u\in\mathbb R^d$, the normalized kernel is $K_h(u)=h^{-d}K(u/h)$. The kernel must satisfy:

1. Non-negativity for all inputs
2. Integration to 1
3. Symmetry

Note that $\sum_{i=1}^{n} w_i = 1$, making this a proper weighted average.

### Limitations of Standard Kernel Regression

When high-fidelity data is limited:
- Predictions suffer from **high variance**
- The estimator is sensitive to the particular training samples drawn
- Accuracy degrades significantly in low-budget regimes

### Multifidelity Setup

To address these limitations, we introduce a **multifidelity framework**:

- $f_2: \mathbb{R}^d \to \mathbb{R}$: low-fidelity input-output map (cheap to evaluate)
- $n$: number of high-fidelity samples
- $m$ $(m \gg n)$: number of low-fidelity samples
- $\alpha$: optimal weight derived from correlation between fidelities

The key insight is that both kernel regression and the MFMC estimator are **mean estimation methods**, allowing us to combine them naturally.

### Multifidelity Kernel Regression

The MFMC estimator for mean estimation is:

$$\mathbb{E}[f_1(X)] \approx \frac{1}{n}\sum_{i=1}^{n} f_1(x_i) + \alpha \left( \frac{1}{m}\sum_{i=1}^{m} f_2(x_i) - \frac{1}{n}\sum_{i=1}^{n} f_2(x_i) \right)$$

Applying this framework to kernel regression:

$$E[Y_1|X=x^\ast] \approx \sum_{i=1}^{n} w_{i,n}(x^\ast) y^{(1)}_i + \alpha \left( \sum_{i=1}^{m} w_{i,m}(x^\ast) y^{(2)}_i - \sum_{i=1}^{n} w_{i,n}(x^\ast) y^{(2)}_i \right)$$

where:
- $w_{i,n}$ are weights computed using the $n$ high-fidelity samples
- $w_{i,m}$ are weights computed using the $m$ low-fidelity samples
- $\alpha$ is optimized to minimize variance

Ordinary MFMC sample means have an exactly zero-mean LF correction. Normalized kernel regressors are ratios of random sums, so their expectations generally depend on sample count and bandwidth. The LF correction is therefore not generally zero-mean at finite sample sizes, and MFKR is not generally exactly unbiased. If both LF smoothers converge to the same target and the coefficient remains bounded in probability, the correction converges to zero in probability. Consistency for the true conditional mean additionally requires shrinking bandwidths, sufficient local sample counts, and standard regularity assumptions.

### Future Study Appendix: Optimal Bifidelity Sample Allocation

The following appendix is retained as future-study background. It is outside
the current theoretical claim. The canonical and more explicit version is
[`docs/future_optimal_allocation.md`](docs/future_optimal_allocation.md).
The derivation below minimizes the leading sampling variance of bifidelity kernel regression. The formulas are exact for ordinary MFMC sample means and asymptotic for kernel regression. They do not establish an exact finite-sample MSE optimum when bandwidths, smoothing bias, or estimated control coefficients change with the allocation.

#### Setup and assumptions

Fix a query $z\in\mathbb R^d$. Let $H$ and $L$ denote the HF and LF labels, and let $Y_q=f_q(X)$ be the scalar output at fidelity $q\in\{H,L\}$. Let $n$ be the HF sample count and $m\ge n$ the **total** LF sample count, including the $n$ LF observations paired with HF observations. Let $c_H>0$ and $c_L>0$ be the costs of one HF and LF evaluation, respectively, and let $P>0$ be the training budget. The cost constraint is

$$
c_Hn+c_Lm\le P.
$$

Assume:

1. The inputs $X_1,\ldots,X_m$ are independent and identically distributed. HF and LF outputs are paired at the first $n$ inputs.
2. The HF bandwidth $h_H$ and LF bandwidth $h_L$ are fixed across candidate allocations, or are selected using independent pilot observations and then held fixed. Both LF smoothers use the same $h_L$.
3. Kernel denominator expectations are positive, the influence variables defined below have finite second moments, and the ratio expansion is valid. For variance conclusions, assume the expansion remainder is negligible in mean square at the leading sampling scale.
4. Population influence moments and the optimal coefficient are treated as known. In practice they are estimated from pilot observations; their estimation error is excluded from the following variance objective.

All expectations and covariances below refer to the input/output sampling distribution, conditional on any independently selected bandwidths.

#### From kernel ratios to sample means

For an available sample count $k$ at fidelity $q$, define the numerator average $a_{q,k}$, denominator average $b_{q,k}$, and their population expectations $a_q$ and $b_q$ by

$$
a_{q,k}=\frac1k\sum_{i=1}^k K_{h_q}(z-X_i)Y_{q,i},
\qquad
b_{q,k}=\frac1k\sum_{i=1}^k K_{h_q}(z-X_i),
$$

$$
a_q=\mathbb E[K_{h_q}(z-X)Y_q],
\qquad
b_q=\mathbb E[K_{h_q}(z-X)]>0.
$$

The kernel predictor is $\widehat\mu_{q,k}=a_{q,k}/b_{q,k}$, and its fixed-bandwidth population target is $\mu_{q,h_q}=a_q/b_q$. The target $\mu_{q,h_q}$ generally differs from the true conditional mean $\mathbb E[Y_q\mid X=z]$.

Define the influence variable

$$
\psi_q(X,Y_q;z)
=\frac{K_{h_q}(z-X)(Y_q-\mu_{q,h_q})}{b_q}.
$$

Its expectation is zero because $a_q-\mu_{q,h_q}b_q=0$. Expanding the ratio around $(a_q,b_q)$ gives

$$
\widehat\mu_{q,k}-\mu_{q,h_q}
=\frac{a_{q,k}-a_q}{b_q}
-\frac{a_q}{b_q^2}(b_{q,k}-b_q)
+o_p(k^{-1/2})
=\frac1k\sum_{i=1}^k\psi_{q,i}+o_p(k^{-1/2}).
$$

Here $\psi_{q,i}=\psi_q(X_i,Y_{q,i};z)$, and $o_p(k^{-1/2})$ denotes a remainder whose product with $\sqrt{k}$ converges to zero in probability. The additional mean-square remainder assumption above permits using the expansion to compute leading variances.

Define

$$
v_H=\operatorname{Var}(\psi_H),\qquad
v_L=\operatorname{Var}(\psi_L),\qquad
C=\operatorname{Cov}(\psi_H,\psi_L),\qquad
\rho_K=\frac{C}{\sqrt{v_Hv_L}}.
$$

Initially assume $v_H,v_L>0$. These quantities depend on the query and bandwidths. In particular, $\rho_K$ is an influence correlation, not generally the correlation between raw outputs $Y_H$ and $Y_L$.

#### Optimal coefficient and variance

Let $\bar\psi_{q,k}=k^{-1}\sum_{i=1}^k\psi_{q,i}$ denote an influence sample mean, and let $D_\psi=\bar\psi_{L,m}-\bar\psi_{L,n}$. The leading random part of the MF predictor is

$$
\bar\psi_{H,n}+\alpha D_\psi.
$$

Only matching sample indices contribute to covariance. Since the first $n$ LF observations occur in both LF means,

$$
\operatorname{Cov}(\bar\psi_{L,m},\bar\psi_{L,n})=\frac{v_L}{m},
\quad
\operatorname{Cov}(\bar\psi_{H,n},\bar\psi_{L,m})=\frac{C}{m},
\quad
\operatorname{Cov}(\bar\psi_{H,n},\bar\psi_{L,n})=\frac{C}{n}.
$$

Consequently,

$$
\operatorname{Var}(D_\psi)=v_L\left(\frac1n-\frac1m\right),
\qquad
\operatorname{Cov}(\bar\psi_{H,n},D_\psi)
=-C\left(\frac1n-\frac1m\right).
$$

Let $V(\alpha,n,m)$ denote the variance of the leading random part. Then

$$
V(\alpha,n,m)
=\frac{v_H}{n}
+\left(\frac1n-\frac1m\right)(\alpha^2v_L-2\alpha C).
$$

For $m>n$, differentiation with respect to $\alpha$ gives the minimum at

$$
\boxed{\alpha^*=\frac{C}{v_L}
=\rho_K\sqrt{\frac{v_H}{v_L}}.}
$$

For $m=n$, the two LF smoothers coincide exactly and the correction is zero for every coefficient. Substituting $\alpha^*$, define the nonnegative constants

$$
A=v_H-\frac{C^2}{v_L}=v_H(1-\rho_K^2),
\qquad
B=\frac{C^2}{v_L}=v_H\rho_K^2.
$$

Nonnegativity follows from the covariance inequality $C^2\le v_Hv_L$. The minimized leading variance is

$$
\boxed{V^*(n,m)=\frac{A}{n}+\frac{B}{m}.}
$$

At the same HF count $n$, the reduction relative to SF is $B(1/n-1/m)\ge0$. This statement concerns leading variance with the population coefficient, rather than error on every realized training dataset.

#### Continuous budget allocation

First suppose $A,B>0$ and ignore integer restrictions. The objective decreases when either count increases, so an optimum uses the full budget. Introduce a Lagrange multiplier $\lambda$ and define

$$
\mathcal L(n,m,\lambda)
=\frac{A}{n}+\frac{B}{m}
+\lambda(c_Hn+c_Lm-P).
$$

An interior optimum satisfies

$$
\frac{\partial\mathcal L}{\partial n}
=-\frac{A}{n^2}+\lambda c_H=0,
\qquad
\frac{\partial\mathcal L}{\partial m}
=-\frac{B}{m^2}+\lambda c_L=0.
$$

Equating the two expressions for $\lambda$ gives the unconstrained count ratio $r_0$:

$$
\boxed{
r_0=\frac{m}{n}
=\sqrt{\frac{Bc_H}{Ac_L}}
=\sqrt{\frac{c_H\rho_K^2}{c_L(1-\rho_K^2)}}.
}
$$

The objective $A/n+B/m$ is strictly convex for positive counts, so a feasible stationary point is the global minimum. To impose nesting, define $r^*=\max(1,r_0)$. Indeed, writing $m=rn$ and eliminating $n$ with the budget constraint gives

$$
V^*(r)=\frac{(A+B/r)(c_H+c_Lr)}{P},\qquad r\ge1,
$$

$$
\frac{dV^*(r)}{dr}
=\frac{Ac_L-Bc_H/r^2}{P}.
$$

If $r_0<1$, that derivative is positive throughout $r\ge1$, so the optimum is the boundary $r=1$. The nested continuous allocation is therefore

$$
\boxed{
n^*=\frac{P}{c_H+c_Lr^*},
\qquad
m^*=\frac{Pr^*}{c_H+c_Lr^*}.
}
$$

These formulas assume no active minimum-count requirement. If $n$ must exceed a specified minimum, the optimum must also respect that boundary.

#### Integer counts and degenerate cases

Let $n_{\min}\ge1$ be the required integer HF count. For each feasible integer

$$
n_{\min}\le n\le\left\lfloor\frac{P}{c_H+c_L}\right\rfloor,
$$

define the largest affordable LF count

$$
m(n)=\left\lfloor\frac{P-c_Hn}{c_L}\right\rfloor.
$$

For a fixed $n$, the objective is nonincreasing in $m$, so $m(n)$ is an optimal LF count. Evaluating $A/n+B/m(n)$ over every feasible $n$ therefore finds a global integer optimum for this variance model. This is the approach in `optimal_mfkr_experiment/optimal_mfkr.py::optimal_field_allocation`.

- If $B=0$ and $A>0$, LF provides no leading variance reduction. Within the nested family, maximize $n$; a pure SF design avoids paying for unused LF information.
- If $A=0$ and $B>0$, the leading variance is $B/m$. With a prescribed $n_{\min}$, choose $n=n_{\min}$ and maximize $m$. A very small HF count may invalidate the influence approximation despite minimizing its formula.
- If $A=B=0$, every feasible allocation has zero leading variance. Higher-order error and bias determine accuracy.
- If $v_L=0$, define the correction coefficient as zero and use $A=v_H$, $B=0$; $\rho_K$ is undefined and need not be computed.

#### Comparison with SF at equal cost

For a continuous SF allocation, the HF count is $P/c_H$ and the leading variance is $V_{\mathrm{SF}}=v_Hc_H/P$. At an interior MF optimum, substitution of $n^*$ and $m^*$ yields

$$
V_{\mathrm{MF}}^*
=\frac{(\sqrt{Ac_H}+\sqrt{Bc_L})^2}{P}.
$$

Define $\gamma=c_L/c_H$, the LF-to-HF cost ratio. Then

$$
\frac{V_{\mathrm{MF}}^*}{V_{\mathrm{SF}}}
=\left(\sqrt{1-\rho_K^2}+|\rho_K|\sqrt\gamma\right)^2.
$$

For $0<\gamma<1$ and $0<|\rho_K|<1$, the interior MF allocation strictly improves leading variance at equal cost exactly when

$$
\boxed{\rho_K^2>\frac{4\gamma}{(1+\gamma)^2}.}
$$

To verify the condition, set $t=|\rho_K|$. The desired inequality is $\sqrt{1-t^2}<1-t\sqrt\gamma$. Its right side is positive because $\gamma<1$. Squaring and simplifying gives $t(1+\gamma)>2\sqrt\gamma$, which yields the stated condition. The condition also ensures $r_0>1$. If the nested optimum has $m=n$, MF has no correction and spends part of the budget on LF, so pure SF is preferable. Integer allocation and active minimum counts require a direct comparison with the integer SF count $\lfloor P/c_H\rfloor$.

#### Field objectives, calibration costs, and implementation scope

For a field objective, let $\ell$ index a finite collection of query/output pairs, and let $\omega_\ell\ge0$ be prescribed error weights satisfying $\sum_\ell\omega_\ell=1$. If a separate population-optimal coefficient is used at each pair, define

$$
A_{\mathrm{field}}=\sum_\ell\omega_\ell v_{H,\ell}(1-\rho_{K,\ell}^2),
\qquad
B_{\mathrm{field}}=\sum_\ell\omega_\ell v_{H,\ell}\rho_{K,\ell}^2.
$$

The weighted sum of leading variances is $A_{\mathrm{field}}/n+B_{\mathrm{field}}/m$. Replace $A,B$ with these field constants in the allocation derivation. This objective is a weighted sum of coordinate errors; a non-diagonal field metric or a shared coefficient requires the corresponding joint covariance calculation.

If $s$ paired pilot observations are acquired solely to estimate influence statistics, the total evaluation budget $P_{\mathrm{total}}$ satisfies

$$
s(c_H+c_L)+nc_H+mc_L\le P_{\mathrm{total}}.
$$

For a fixed pilot count, substitute $P=P_{\mathrm{total}}-s(c_H+c_L)$ in the allocation formulas. Optimizing the pilot count as well requires a model for coefficient-estimation error. The documented influence experiment excludes pilot costs and estimates the moments using independent paired pilots. The formulas above treat those estimates as population quantities and do not include their uncertainty.

The baseline `src/mfmc.py::alloc` uses the same algebra with raw-output standard deviations and correlations, and floors the continuous counts separately. Those raw moments provide an exact ordinary-MFMC variance model, but generally differ from kernel influence moments. In addition, `src/kr.py::find_mfsigma` fits the two LF bandwidths separately, so the common-LF-influence cancellation used in this derivation does not directly apply to that baseline. The influence experiment implements the common-bandwidth model and integer search separately from `src/`.

With fixed bandwidths, the limiting HF smoothing bias is independent of $n,m$, so the allocation also minimizes an MSE approximation consisting of that squared bias plus the leading variance. Finite-sample ratio bias, bandwidths refitted at each count, and estimated coefficients can change the optimum. The exact finite-sample MSE coefficient in `optimal_mfkr_experiment/mse_optimal_mfkr.py` addresses a different objective: if $e$ is the SF prediction error and $D$ the LF correction, it minimizes $\mathbb E[(e+\alpha D)^2]$ at $\alpha=-\mathbb E[eD]/\mathbb E[D^2]$. A closed-form allocation for that objective requires additional information about how these moments vary with $n$ and $m$.

### Example 2: NASA CRM Wing Stress Field

**Setup:**
- Input: NASA Common Research Model (CRM) wing design parameters
- High-fidelity output: CRM wing von Mises stress field
- Low-fidelity output: coarse-grid wing stress field
- Number of high-fidelity training samples: 100
- Number of low-fidelity training samples: 300
- Number of test samples: 100

In this example, the multifidelity kernel regression predicts POD coefficients
for unseen input points, then reconstructs the predicted stress field with the
high-fidelity POD basis.
To train the model, we use the MAROM framework from Perron et al. The method applies POD separately
to the high- and low-fidelity datasets and retains the same number of POD modes. It then
uses manifold alignment to map the low-fidelity POD coefficients into the high-fidelity
POD coefficient space.

**Stress Prediction and Pointwise Absolute Error:**

![CRM wing stress field comparison](examples/wing/results/mfkr_field_lowfi_grid.png)

lower error than the single-fidelity prediction across the wing field.

For the coarse-grid low-fidelity data, multifidelity regression reduced the
mean relative L2 error from 4.04% with single-fidelity kernel regression to
2.34%. The worst-case relative L2 error also dropped from 19.55% to 8.80%.

### Example 3: Optimal and Naive UM/ExoPlaSim Allocations

This experiment uses UM as high fidelity and ExoPlaSim as low fidelity. The
data contain 197 exact UM/ExoPlaSim input pairs and 803 additional ExoPlaSim
cases. A deterministic split made with seed `20260910` assigns 100 pairs to an
independent pilot set and the remaining 97 pairs to the training candidate
pool. The 30 target-domain UM cases without generated ExoPlaSim pairs form the
fixed test set. Pilot cases are excluded from every training pool.

The pilot data fit a five-mode UM POD representation, a five-mode ExoPlaSim POD
representation, their scaled orthogonal Procrustes alignment, common LF kernel
bandwidths, and the query-dependent influence coefficient. Training draws use
bootstrap sampling with replacement because some requested allocations exceed
the 97 distinct paired training candidates. Every policy uses the same test
cases, pilot estimates, and matched bootstrap streams. The assumed costs are
$c_H=1$ for one UM observation and $c_L=0.1$ for one ExoPlaSim observation.

The derived allocation is compared with $m=2n$, $m=4n$, $m=6n$, and $m=8n$.
For a naive ratio $r$, the experiment uses

$$
n=\left\lfloor\frac{P}{c_H+rc_L}\right\rfloor,
\qquad m=rn,
$$

so every policy respects the same nominal cost bound. A same-budget
single-fidelity reference spends the complete budget on UM observations.

Three fields were evaluated over budgets 10, 15, 20, 30, 40, 50, 75, 100,
150, 200, 300, and 400 with 30 matched repetitions:

- `surface_temperature`: the pilot influence correlation is weak. The optimal
  rule selects $m/n$ close to one. Single-fidelity UM has lower observed RMSE
  than every tested MF rule.
- `cloud_fraction_8`: the pilot influence correlation is also weak. The optimal
  rule again selects $m/n$ close to one. Its observed mean RMSE is slightly
  below single-fidelity UM at budgets 40, 300, and 400. The fixed ratios are
  unstable at many smaller budgets.
- `olr_cloudy`: the pilot influence correlation is stronger. The optimal rule
  selects $m/n$ near 2.5 to 2.8, but fixed ratio 2 has slightly lower mean RMSE
  at most budgets. Single-fidelity UM still has the lowest mean RMSE at every
  tested budget.

These results do not show uniform MFKR dominance over SFKR for the present data
split and pilot-fitted coefficient. The allocation formula minimizes an
estimated leading-variance objective. The experiment measures finite-sample
field RMSE, which also includes smoothing bias, influence-moment estimation
error, POD truncation error, and behavior caused by resampling a limited paired
pool.

#### Alpha estimated from all available pairs

A second experiment changes only the sample used to estimate the influence
moments and alpha. POD fitting, bandwidth fitting, the 97-pair training pool,
the 900-case LF pool, the test set, and random streams remain fixed. The first
experiment estimates alpha from the 100 independent pilot pairs. The second
experiment estimates alpha from all 197 available UM/ExoPlaSim pairs. Thus, the
second statistics set overlaps all 97 training candidates and is not an
independent alpha evaluation.

Using all 197 pairs did not uniformly improve performance. For surface
temperature, nearly zero estimated local LF influence variances produced
extreme alpha values and severe numerical instability. For cloud fraction
level 8, results changed irregularly across budgets. For cloudy OLR, all-pairs
alpha reduced optimal-allocation mean RMSE modestly at most budgets and beat
the same-budget SF mean at budget 400.

The combined comparison is in
`examples/exoplanet/results/alpha_statistics_pilot100_vs_all197/index.html`.
Run the all-pairs experiment by adding `--statistics-mode all-pairs`, then run
`examples/exoplanet/compare_alpha_statistics_modes.py` to regenerate the
comparison report.

## Prerequisites

Download data for the wing example.

Download the wing structural stress data from [here](https://link.springer.com/article/10.1007/s00158-022-03274-1#Sec23) (3.9 GB), or by running:

```bash
wget https://static-content.springer.com/esm/art%3A10.1007%2Fs00158-022-03274-1/MediaObjects/158_2022_3274_MOESM1_ESM.zip
```

Place the following data into `data/wing`:

```text
/data/crm_baseline_4DV_N1000_slim.h5
/data/crm_coarse-grid_4DV_N1000_slim.h5
/data/crm_coarse-ribs_4DV_N1000_slim.h5
```

Preprocess the data.

For each example, run the script beginning with `preproc_` to generate or format the data.

## Usage

```bash
# Run exponential function example
python examples/exponential/mfkr.py

# Run CRM wing stress-field example
python examples/wing/preproc_wing.py
python examples/wing/mfkr_field.py --low-fidelity grid
```

## Key Features

- **Variance Reduction**: Leverages cheap low-fidelity data to reduce prediction variance
- **Extended Allocation Study**: Includes an experimental first-order allocation method whose assumptions and approximation are documented separately from the current MFKR dominance claim
- **Consistency Conditions**: The LF correction vanishes asymptotically when both LF smoothers converge to the same target and the coefficient remains bounded in probability
- **Kernels**: Supports ARD Matern 3/2 and Exponential kernel functions
- **Parallel Computation**: Uses joblib for parallel cross-validation
